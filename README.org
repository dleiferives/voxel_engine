# Voxel Engine

** Installing
To install the project you have to pull down the code along with its submodules:
#+begin_src
git clone https://github.com/dleiferives/voxel_engine
git submodule init
git submodule update
#+end_src

** Building
You will need clang 17 or 18 (prefereably 18).
You will need to install Vulkan so that it can be built on your computer.
For linux (only tested so far) the instructions for installation can be found [here](https://docs.vulkan.org/tutorial/latest/02_Development_environment.html#_linux_2)

#+begin_src
mkdir build
cd build
cmake ..
cmake --build .
#+end_src
